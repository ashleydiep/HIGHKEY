### Call Dispositions

You can select **multiple dispositions at once** for each call. Tag every call accurately before moving to the next.

| Disposition | Definition |
|-------------|-----------|
| Appointment Set | Confirmed appointment booked → **click "Go High Level" to import to GHL** |
| Hot Lead | Will sell within 30 days |
| Warm Lead | Will sell within 90 days |
| Future Follow Up | Interested but not ready yet — needs ongoing follow-up |
| Investor | Lead is an investor, not a traditional seller |
| Rental | Lead is a renter or rental property owner |
| Needs Skiptrace | No working numbers — flag for skiptrace research |
| Property Listed | Property is already listed with another agent |
| Property Sold | Property has already sold |
| Dead | Not interested, do not contact again |

> **Important:** When you mark Appointment Set, click "Go High Level" in MOJO to import the contact directly into CRM.

## 2. CRM Platform — Go High Level (GHL)

GHL is where all contacts, pipelines, and follow-up sequences live. Every contact you speak with should be logged here.

**Access:** Login credentials will be provided by Ashley.

### Adding & Updating Contacts

When adding or updating a contact in GHL:

1. **Tag the lead category** — always tag what type of lead they are:
   - Expireds
   - Absentee
   - Vacant
   - Newsletter
   - Circle Prospecting
   *(add others as applicable)*

2. **Tag "ISA"** — add the ISA tag on every contact you create or update so Ashley can identify all leads coming from you

3. **Update the notes section every time** — after every conversation, add a note with:
   - Date of call
   - What was discussed
   - Next step or follow-up needed

> Never leave a contact without a note after a conversation.

## 3. Google Calendar

Used for scheduling appointments with sellers.

**Access:** Ashley will provide access to the shared calendar.

### Booking an Appointment

1. Create a calendar invite at the confirmed date and time
2. **Invite Ashley** into the calendar event
3. Include in the invite:
   - Seller's full name
   - Property address
   - Seller's phone number
4. Confirm all details with the seller before ending the call

## Daily ISA Workflow

1. **Pull your list** — Export contacts from ArchAgent (expireds) or REDX (circle prospecting)
2. **Load into MOJO** — Import the list and set up your dialing session
3. **Dial + disposition every call** — Select all applicable dispositions before moving on
4. **Appointment set?** — Click "Go High Level" in MOJO → book calendar invite → invite Ashley
5. **Log in GHL** — Add lead category tag + ISA tag, update notes section after every conversation
6. **Report end-of-day numbers** — Contacts made, appts set, hot/warm leads, callbacks
